- In the table, **PASS/FAIL/REVIEW** are proposed rule-level outcomes, not a verdict for a whole dossier. Any conclusive statutory FAIL blocks the proposed group; uncertainty, missing evidence or unimplemented derogation is REVIEW. An **OUT_OF_SCOPE** applicability decision is separate, never a chemical-grouping PASS.
- Test IDs `P*/N*/R*/S*/M*` are scenarios already described in `docs/acceptance-tests.md`; `A-*` are **proposed** regulatory QA scenarios for Agent F to implement, not automated passing tests. Each hard gate has a positive, negative and missing-evidence case; status of executing those tests remains **NOT IMPLEMENTED** until Agent F confirms.

## Numerical contract handed to Agents C/E/F

1. Use `Decimal` or decimal **strings**; never IEEE-754 floats or tolerance/rounding to obtain legal eligibility. Percentages and band widths are **percentage points**. The three values `5.0000`, `5.0001`, and `4.9999` must remain distinct.
2. Table rows apply to the concentration **represented by any point within a proposed reported range**. For a range crossing a boundary, enforce the most restrictive width for **every intersected zone**. ECHA v6.0 §5.3.3.3, Example 19: major concern exact 26% permits `23–26`, `25–30`; **not** `24–29`. For 9.7–10.5 major concern, width 0.8 ≤1 and ≤3 => permissible; for 9–11, width 2 >1 => not.
3. Band thresholds `0`, `0.1`, `1`, `10`, `25`, `100` must have exact endpoint semantics as printed in Tables 1–2; **zero** is not positive concentration and **100** is outside the printed `<100` band. An exact 100% declaration needs separate scope review before applying a width rule. The legal tables are zone definitions, not an authorisation to insert absent ingredients at 0%.
4. If inputs are bounded intervals, choose a declaration covering their **union**, not merely estimated midpoints; any uncertainty overlapping an eligibility boundary without proving a pass/fail => REVIEW.
5. The perfume threshold adds only the actual concentrations of **identity/presence-varying** perfumes (not all perfumes). Compare **each entire proposed group**, not pairwise unions. A shared perfume is still an ordinary common notified component requiring its valid declaration unless a statutory omission applies.
6. `B.4.1/Table 4` is **relative variation** of a prior **exact** declared value for updates; it is not a way around B.3.4 Tables 1–2 during grouping. Table 4 breakpoints: `>25`: 5% relative; `>10–≤25`: 10%; `>2.5–≤10`: 20%; `≤2.5`: 30%.

## ECHA worked-example reconciliation (guidance, **not golden fixture tests yet**)

- **Example 19, printed p.69 / PDF p.70:** major concern 26% may be declared 23–26 (width 3 reaches below 25) or 25–30 (width 5 wholly at/above 25); reject 24–29 (width 5 crosses zone with width 3). Supports crossing-band approach.
- **Example 22, printed pp.72–73 / PDF pp.73–74:** three products differing in non-hazardous colourant identities (18%, 21%, 16%) share a **verified** “colouring agents” GCI declared 14–22%; this is **not** a generic waiver of A.4.2 for arbitrary colourants.
- **Example 23, printed pp.77–78 / PDF pp.78–79:** Trade name 1 differing perfumes have actuals **1.2 + 0.6 + 1.0 = 2.8%**; Trade name 2 **0.4 + 1.4 + 1.4 = 3.2%**. “Perfume chemical name 5” is present in both and excluded from the differing-perfume cap; varying perfume MiM UFI evidence and a non-classified perfume GCI are shown.
- **Example 24, printed pp.79–80 / PDF pp.80–81:** ABC includes perfume MiM A plus B, BCD includes perfume GCI, CDE includes MiM B plus perfume GCI. B and GCI are **not** common to all three; each mixture's relevant varying perfumes must total ≤5%; the guidance does not supply actual formulation values needed to turn this directly into an exact-input engine golden test. MiM B with no UFI requires the available SDS-component and supplier route. Preserve the member–perfume–classification mapping.
